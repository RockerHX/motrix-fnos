## 2.0.0 剩余验收

以 [实机检查表](maintenance.md#实机验收)逐项记录，不把本地或 macOS 通过当作 Linux / fnOS 通过。

- fnOS 核心：新装登录、升级向导提示旧任务不导入、旧任务与旧操作不阻止升级；确认新列表为空而文件、密码、设置、授权与 RPC Token 保留；手动备份回滚一次，FPK 不含独立 checker。
- 下载与数据安全：HTTP/HTTPS、种子、磁链、中文多文件选择、暂停续传、回收站恢复、删除不越界、应用及设备重启、实时进度；完成文件核对 hash，外部 RPC 核对提交与 Token 隔离。
- Linux 补验：中文路径 C/C.UTF-8、异常源安全处置、同名 / 无 Range 防覆盖、BT 路径归属与敏感 Header；命令见 [固定候选测试](maintenance.md#固定引擎候选测试)。
- 架构：ARM 完成核心操作；x86_64 至少验证对应包安装升级、启动、HTTP 和中文 BT，没有设备就保留未验证。
- 发布：最终双架构 FPK、SBOM、校验和、发布说明及 workflow 构建证明一致；候选包不代表正式发布。

### 已知限制与延期

- 2.8.6 遇异常 Content-Range 可能一直 active 且普通暂停无效；应用确认超时后报错并保留文件，需要停服重启，强制结束后未提交进度可能回退。安全处置通过不等于引擎缺陷已修复。
- HTTP/SOCKS4 的部分 BT 域名依赖本机 DNS；BT 自定义 HTTP Header 不传 tracker/web-seed。发布说明必须明确这些限制。
- 长时压测、完整网络抓包和性能对比延期，不作为本次门槛，也不记为已通过；真实代理验收有环境再补，无环境保留未验证。

## 命名访问密钥的待规划要求

以下是后续方案评审边界，不代表已经实现：

- 提供创建、重命名、轮换、撤销和列表；展示名称、入口作用域、掩码、创建时间与最后使用时间。单密钥变更不影响其他客户端。
- 服务端用系统随机源生成至少 32 字节随机密钥；创建或轮换后原文只显示一次，关闭弹窗或离页立即清除，不出现在普通查询、日志、诊断及导出中。
- 优先持久化不可逆摘要或等价验证材料；管理写操作需要管理员 JWT，数据库失败不得改变内存有效密钥集合。兼容阶段若需旧明文，先明确迁移完成条件与清理路径。
- 鉴权只用内存与常量时间比较，不读 SQLite；最后使用时间在内存聚合并限频保存，退出尽力持久化，统计失败不影响合法请求或导致高频磁盘写入。
- 旧公网 / 局域网 Token 幂等迁移为对应作用域的兼容密钥，持久化成功才标记完成；失败保持旧凭据可用并提供诊断。不设强制失效日期，迁移不打断既有客户端。
- 不通过 Header 或来源推断扩大作用域；指南和诊断按入口展示状态。无密钥、全部撤销、迁移中及保存失败须有明确反馈，失败回滚前端受控状态。
- 回滚前明确旧版能否读取兼容凭据；不能保证时保留可恢复信息并写入发布说明。
- 测试覆盖 HTTP、WebSocket、batch、multicall 的逐调用作用域、跨入口拒绝、即时撤销、数据库关闭后鉴权、迁移幂等与失败、轮换、一次性原文、重启及限频写入；补 Lucky、RFC1918 客户端和至少一种外部发送工具验收。
