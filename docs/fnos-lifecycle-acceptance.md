## 启停和重启

1. 执行 `appcenter-cli start motrix`，随后执行 `appcenter-cli list` 和 `cmd/status`。
2. 确认状态同时包含正确 PID、可执行文件身份、进程启动时间和服务就绪结果。
3. 执行 `appcenter-cli stop motrix`，确认 PID 文件、端口和 Aria2 sidecar 均退出。
4. 重复启动/停止各一次，确认不会留下陈旧 PID 或重复 sidecar。
5. 重启 fnOS 设备，确认应用按配置自动启动，任务状态和 session 可恢复。

通过标准：服务未就绪时 `start`/`status` 明确失败或降级；伪 PID、错误端口和重复进程不能被识别为正常运行。

## 卸载和回滚

1. 在卸载前记录任务数量、设置摘要、SQLite 完整性、Aria2 session 和用户文件位置。
2. 默认卸载（不勾选删除应用数据），确认进程、监听端口和注册服务清理，`TRIM_PKGVAR` 保留。
3. 重新安装同一 `motrix` 身份，确认任务、设置、session 和登录初始化行为符合文档。
4. 按发布策略恢复旧 FPK 和升级前数据备份，确认旧版能启动并读取任务。
5. 如验证“删除应用数据”选项，只确认应用私有目录被清理，不触碰用户下载目录。

通过标准：停止、卸载和回滚不会误删用户文件；数据保留/删除与用户选择一致。任何失败都应记录原始日志和截图，不得写成通过。
