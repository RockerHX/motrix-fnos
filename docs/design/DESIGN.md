# Motrix fnOS UI 规范

本文件合并产品交互与视觉要求，修改 UI 时查阅。[现状] 为已经实现的行为，[确认] 为已批准但未必全部实现的要求，[候选] 不进入当前实施。阶段进度见 [开发计划](../future-development-plan.md)，数据与安全语义见 [接口契约](../api-contract.md)。

## 布局与主题

- 保留 fnOS 工具型界面和当前主流程：高信息密度、低动效、可预测对齐，不做整体 UI 重设计。
- [现状] 桌面侧栏、顶部工具栏和主内容；移动端单列、底部导航和触控卡片，共用业务状态，分层见 [架构](../architecture.md#4-前端与数据流)。
- [确认] 导航为全部、下载中、已完成、回收站、扩展，默认全部；全部排除回收站，并在页面内筛选暂停和错误，不新增“已停止”一级分类。
- [现状] 设置、帮助、关于、诊断是辅助入口，诊断可打开调试日志；后续维护保持这些关系。
- 独立浏览器默认深色；fnOS 桌面宿主跟随并监听主题，移动 WebView 只初始化一次；统一由 NConfigProvider 控制，组件不自行判断宿主或主题。
- [确认] Motrix 已保存语言优先，只有无本地偏好的登录前初始化才采用宿主语言；配置加载后由 Motrix 设置接管。布局同时容纳中英文。

| 屏幕 | 布局要求 |
| --- | --- |
| `< 768px` | 单列、底部导航、14–16px gutter，弹窗接近全宽，避让安全区和软键盘 |
| `768–1023px` | 保留桌面语义，压缩留白，次要字段换行或收纳 |
| `>= 1024px` | 侧栏与工具栏稳定，任务信息横向组织，充分利用宽度，不强制窄容器 |

## 任务列表与分类

- [确认] 桌面与窄桌面使用 Naive UI 纵向列表和克制分隔线，不加状态竖轨、常驻卡片阴影或逐项圆角边框；移动端使用单列触控卡片。
- [现状] 展示名称、URL、状态、进度、已下载 / 总大小、速度、ETA 和错误；区分等待、下载、暂停、完成、错误、删除、磁链解析及等待确认。
- [现状] 按任务状态提供暂停、继续、文件确认、重下载、移入回收站、恢复、永久删除及详情；工具栏提供创建、刷新和当前可见任务批量操作，不可执行时禁用。
- [确认] 前端分页默认 20 条，可选 20 / 50 / 100；普通批量仅作用当前页，清空回收站作用全部回收站。
- [确认] 进度条独占稳定行，已下载量、剩余时间、速度各有稳定信息槽；数字变化不挤动相邻内容，未知总大小用明确占位。
- [现状] 列表和详情的百分比统一取当前有效快照的已下载量 / 总大小，保留一位小数，允许真实进度修正，不按完成状态补算下载量；未完成最高显示 99.9%，回收站保留已完成的历史进度。总大小未知、磁链解析和待确认时显示 `--`，进度条不提供确定数值。
- [现状] 剩余时间按当前速度估算并标注“约”，中英文分别显示对应单位；最多展示两个相邻时间单位，超过一小时省略秒，超过一天展示天 / 小时，零值次级单位省略。
- [现状] 列表进度条下只展示已下载 / 总大小、速度和剩余时间，分类保留在详情。桌面保持三个稳定信息槽；手机大小独占一行、速度与剩余时间并排，卡片按内容确定高度，列表滚动而不压缩卡片。只有内容下载中显示实时速度和 ETA，暂停、完成、排队、错误、回收站及磁链解析 / 待确认时使用 `--`，未知总大小仍保留已下载量和速度；磁链解析不展示 metadata 传输量。
- [确认] 普通删除明确提示“移入回收站，保留文件，不释放空间”，不提供删除文件勾选。单任务永久删除与清空回收站都提供默认不勾选的“同时删除下载文件（不可恢复）”，需二次确认。
- [确认] 未进入内容下载的解析 / 待确认磁链、内容已删除记录不显示删文件选项；混合清空时逐条判断，只有含可删除内容才显示选项，不按预览文件大小推断内容已落盘。
- [确认] 未完成任务恢复显示暂停并保留进度，完成历史保持完成；旧记录文件已删时须明确确认从头下载。清理中继续显示记录、禁止恢复及重复删除，失败可诊断并自动重试，完成才移除；后台提交成功不能显示成文件已删除。底层恢复 / 删除规则见 [任务契约](../api-contract.md#44-任务)。
- [确认] 完成任务在 fnOS 宿主主操作区提供“在文件管理器中打开”，详情按后端上下文提供“打开文件”“文件详情”；非单文件隐藏打开文件，非宿主隐藏操作并说明限制。每次宿主操作重新按任务 ID 查询上下文，不使用缓存路径。
- [确认] 默认展示语义保存路径 / 文件路径，真实路径在折叠“技术信息”中并可复制。长名称、URL、路径稳定省略或换行，不能挤出操作按钮。
- [现状] 各分类空状态有标题和说明；移动端可提供添加 / 设置，桌面依靠工具栏和侧栏。退出或分类不允许创建时禁用，不显示静态假按钮。

## 新建与文件确认

- [确认] 同一弹窗提供链接、种子、磁力三种输入。单 / 多 HTTP 链接共用每行一条的批量创建，不提供自定义文件名；允许部分成功并列出失败条目。
- [现状] 提供授权目录、立即开始 / 添加后暂停、分类、HTTP 连接上限和单任务限速。HTTP 任务代理默认关闭，BT 只用设置页总开关。
- [现状] 校验 URL、磁链、种子和目录；目录加载、失败、空授权均有反馈。提交中限制关闭与重复提交，成功关闭，失败保留输入。
- [现状] fnOS 桌面和飞牛 App 在设置及创建无目录状态提供“添加授权目录”；成功后等待后端官方查询确认，不直接用 SDK 路径。取消不改目录，普通用户提示需管理员，刷新失败保留旧状态并提示可能过期。
- [现状] 独立浏览器、旧 fnOS 或 SDK 失败时不调 App runtime，只提示到应用中心授权；设置仍可重新读服务端快照。
- [确认] 目录选择器显示当前语言的语义路径，提交真实路径；转换失败显示真实路径，语言改变后重取展示数据。
- [现状] 磁链解析后暂停等待文件确认，默认全选，显示路径与大小；关闭保留待确认状态，确认前不向用户目录写内容。至少选一个文件，提交中禁止关闭和改选择，成功后下载。
- [确认] 文件选择桌面可用紧凑表格，移动可触控、不横向溢出；明确区分解析中、等待确认、确认提交中和开始下载。

## 设置与辅助页面

### 设置

- [现状] 包含共享授权、默认目录、并发、HTTP 连接上限 1–64、超时、重试、全局限速、语言、下载代理和两类 RPC 配置，不提供分片数 / 最小分片大小。加载或保存失败、空路径及未授权路径影响提示和按钮状态。
- [现状] BT 总代理显示已应用、延后或受阻；协议、引用保护与失败语义见 [设置契约](../api-contract.md#45-设置)，不静默直连。
- [确认] 公网与 LAN 分别展示入口和 Token 状态；LAN 首次生成 / 轮换的一次性原文弹窗，关闭入口保留凭据，轮换须确认并提示旧客户端失效。来源范围扩大须先说明影响。
- [确认] 通过 RFC1918 IPv4 访问时提供实际 LAN 地址复制；域名访问提供替换 NAS 局域网 IP 的模板，目录只选已授权路径。
- [确认] 复制先用 Clipboard API；仅安全顶层页面允许临时输入框 + execCommand 降级。局域网 HTTP / iframe 可能虚报成功，须保留可选文本并提示手动复制；LAN Token 失败后聚焦全选，临时节点立即清理，Token 不入日志。

### 关于、帮助与诊断

- [现状] 关于展示名称、版本、维护者、目标架构、仓库、匹配架构下载和最近更新；检测有未检查、检查中、有更新、最新、不可用状态。JSON-RPC 完整指南放独立窗格，不与版本历史混排。
- [现状] 帮助覆盖授权、下载设置、RPC、开机自启、回收站、扩展和诊断，明确已启用、待实现、占位或排障属性，不伪装可操作功能。
- [现状] 诊断展示后端、通信、Aria2 进程 / RPC，提供引擎控制和刷新；[确认] 分开展示回环 / LAN 入口、开关、Token 是否配置和指南，不显示原文。
- [现状] 展示 Aria2、Rust、生命周期及总日志占用，区分当前 / 历史字节和文件数，80 MiB 起文字警告；刷新、导出、切模式及清理后更新。
- [现状] 提供 30 分钟详细日志、倒计时与延后生效提示，脱敏导出及停止引擎后确认清理。具体操作与轮转上限见 [日志排障](../maintenance.md#先从页面收集诊断)。
- [现状] 调试日志按级别 / 分类筛选，显示重复折叠、刷新和清空；明确内存记录清空不释放 Aria2 文件空间。覆盖加载、连接失败、空日志、操作中和错误反馈。
- 诊断只通过 JWT 管理 API，不开放给外部 RPC；页面不显示绝对日志路径或凭据。

## 登录与安全交互

- [确认] 启动先查 auth/status，确认访问权前不挂载主窗口、不请求业务数据或 SSE。setupRequired 显示密码缺失恢复提示与脱敏诊断，其余未认证显示登录；不提供网页初始化。
- 恢复 / 登录为独立全屏品牌卡片，不显示侧栏、顶栏、任务骨架、路径、版本检测或其他业务数据。桌面宽 400–440px，手机为视口减 32px，避让安全区与软键盘。
- 加载只显示品牌、状态和 NSpin；失败使用 NAlert + 重试，不显示内部错误。中英文切换紧凑，不争夺密码表单主层级。
- [确认] 安装向导设密并确认，网页登录只有密码；8–128 个 Unicode 字符、不裁剪、可含空格，推荐 12 字以上短语。密码不持久存储，鉴权细节见 [API](../api-contract.md#41-web-管理鉴权)。
- 使用 NForm 受控校验，当前密码 / 登录为 autocomplete=current-password，新密码为 new-password；支持密码管理器、回车单次提交、loading / disabled 和错误后聚焦。改密须当前密码，独立弹窗禁止点遮罩误关，关闭后清输入与校验。
- [确认] JWT 失效 / API 401 时卸载主窗口、停 SSE、清敏感前端状态并回登录；密码缺失回恢复提示。server 重启不自动使有效 JWT 失效，重连先复核鉴权。多标签页只同步退出 / 改密事件，不广播凭据。
- [确认] 设置提供改密和退出；Token 普通读取仅显示服务端掩码，生成或轮换原文只短暂显示，保存或关闭立即清空。清除公网 Token 二次确认并说明公网 addUri 不可用，不展示旧原文。
- [现状] 状态不兼容时持续显示恢复指引，保留登录 / 查询 / 诊断并约束下载按钮；暂停未确认显示错误，不假暂停或继续删除。

## 视觉与组件

### 颜色与现有差异

顶部 YAML 保留完整设计色值、字体、间距和圆角配置。shell / canvas / surface 表示结构层级，text 表示主次信息，accent 为唯一品牌蓝；状态色只表达状态。运行时使用 `src/styles/tokens.css` 的 `--app-*` 及 `NaiveProvider.vue` 的主题覆盖，不在业务组件硬编码主题色。

| 状态色 | 深色 | 浅色 |
| --- | --- | --- |
| 成功 | `#68AE5A` | `#4F9145` |
| 警告 | `#D5A64A` | `#9B6C12` |
| 危险 | `#D56A6A` | `#B64040` |
| 信息 | `#6F9FC7` | `#39749E` |

保留既有设计与实现差异，不因文档合并改界面：

| 项目 | 设计 | 运行时 |
| --- | --- | --- |
| 深色面板 | `#142236` | `--app-color-surface` 与 Naive UI card/modal 为 `#151515` |
| 深色主文本 | `#F4F8FD` | `--app-text-primary` 与 Naive UI textColorBase 为 `#DCE8E2` |
| 圆角 | 输入 / 按钮 6px、任务 / 小面板 8px、弹窗 10px | Naive UI 通用 7px；全局 sm/md/lg/xl 为 12/14/16/18px，另有组件覆盖 |

### 字体、间距与控件

- 使用 YAML 系统字体栈，不下载字体。标题 20/28/600，弹窗标题 18/26/600，任务名 15/22/600，正文 14/21/400，辅助最小 12/18；数值用 tabular-nums，GID / Token / 日志可用系统等宽字体。禁止全大写、超大标题和装饰字距。
- 间距用 4px 基线（4/8/12/16/20/24/32），任务内 8–12，桌面 gutter 24，移动 14–16；边框默认 1px，层级靠间距和边框，阴影只用于弹窗 / 浮层，不卡片套卡片，pill 仅用于有意义状态。
- 优先 Naive UI 按钮、菜单、表单、进度、标签、弹窗等原语；只有缺合适原语且主题 CSS 无法满足时才评估自定义并记录原因。保持原生语义、键盘、focus、disabled、loading 和 ARIA。
- 导航选中使用浅强调背景、强调图标和高对比文字；创建为主操作，批量为次级 / 图标操作；任务名与状态优先、错误就近呈现，桌面操作稳定靠右，手机有明确触控区。
- 表单标签上置、帮助 / 错误下置，状态变化不改尺寸；弹窗内容可滚、操作区固定；状态标签含文字，进度不与数值重叠。
- 空状态用现有图标、短说明与真实下一步；按钮操作局部 loading，首次内容可用匹配骨架，避免全屏 spinner；错误就近或用现有 message，不用夸张语气。

### 图标、动效与可访问性

- 通用图标只用 @tabler/icons-vue，经项目适配层复用；Naive UI 内置加载、清除、分页等图标保持默认，不再封装。自定义仅限品牌、平台专属或 Tabler 无合适语义，须记来源 / 许可证并遵守现有 24×24 viewBox、线宽、端点规则。
- 同操作同图标，刷新 / 重下载、关闭 / 删除、普通 / 永久删除不得混用；危险操作用危险语义，状态同时有文字 / 图标，不只靠颜色。
- 状态动画 120–180ms，弹窗不超 200ms；只动 transform / opacity，pressed 最多位移 1px，hover 不缩放 / 改尺寸。减少动态偏好关闭非必要动画，SSE 不造成闪烁、重排抖动或反复入场。
- 触控目标至少 44×44px，正文至少 14px，文本对比度 WCAG AA，焦点环至少 2px，焦点顺序与阅读顺序一致。不得页面级横向滚动、固定高度裁动态内容或绝对定位重叠。

## 候选与禁止项

以下候选未经排期不实现，不显示可点击假功能：搜索、右键菜单、底部全局状态栏、额外任务一级分类 / 分类徽标、详情抽屉 / 多标签详情、当前宿主文件操作之外的目录操作、复制链接、任务编辑 / 下载凭据 / 备注、通知、开机自启、关闭行为、完成动作和恢复默认；也不开放引擎路径 / RPC 端口 / 数据库位置 / 常驻日志级别设置。现有临时详细日志不属候选。

视觉上不使用 Hero、营销 Dashboard、宣传区、滚动叙事、玻璃拟态、装饰渐变、霓虹、噪点、漂浮装饰、纯黑或大片高亮白、多品牌强调、超大圆角、嵌套卡片和等宽营销三卡布局；不加动画库、字体包、其他通用图标库或非标准 canvas 控件，不用静态 HTML / 未评审组件替代既有 Vue + Naive UI。

## 验收

- 深 / 浅主题 × 中 / 英文分别覆盖 390×844、1024×768、1440×900；核对长文件名、URL、语义与折叠真实路径、非整数动态数值、任务详情和滚动，不改变导航、数据流或已有操作。
- 各适用场景覆盖默认、hover、pressed、focus、loading、empty、error、disabled、selected 和 runtime exiting；不可用需可理解，退出禁止任务写操作，错误有重试 / 修正路径。
- 登录前不闪业务数据，覆盖缺密恢复、登录、退出、JWT 失效、安装向导设密；检查手机软键盘和 Token 一次性原文清理。
- 日志指标、倒计时、清理确认和错误不横向溢出，移动指标单列；导出 / 清理始终受管理鉴权约束。
- 视觉、触控和真实 WebView 不能只由自动化通过推定；设备步骤见 [实机验收](../maintenance.md#实机验收)。
